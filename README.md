## 🧰 Event ops toolkit

One loop, three tools: **decide → execute → learn.**

| | Project | What it does |
|---|---|---|
| **Before** | [**event-vetting**](https://github.com/parker-lauren/event-vetting) | Is this sponsorship worth it? Scores the room, counts real ICP prospects, and turns the price into a meeting target and the close rate it implies. |
| **After** | [**event-contact-list**](https://github.com/parker-lauren/event-contact-list) | Raw badge scans → a clean, deduped, enriched CRM-ready CSV, with zero do-not-contact leaks. |
| **Close the loop** | [**event-debrief**](https://github.com/parker-lauren/event-debrief) | A scheduled, fully sourced debrief draft three days after every event. AI gathers the evidence and people make the call. |

## 💡 How I work

- **Write down what an event has to produce *before* buying it.** "This sponsorship needs 16 meetings" beats "it feels like a good room."
- **Every number has a source.** If it isn't sourced, it's a question, not an estimate.
- **AI drafts, people decide.** The tools do the gathering and arithmetic; judgment and outcomes stay with the team.
